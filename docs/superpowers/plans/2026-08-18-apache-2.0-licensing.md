# Apache-2.0 Licensing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** License all eligible project-authored repository material under Apache-2.0 and make that grant detectable in package metadata, public documentation, and GitHub.

**Architecture:** A root `LICENSE` is the authoritative grant, while `NOTICE`, Python package metadata, README language, third-party boundaries, and contribution terms make its scope explicit. A static release-contract test prevents a later release from silently returning to an unlicensed or ambiguously licensed state.

**Tech Stack:** Apache License 2.0, SPDX metadata, Markdown, TOML, pytest, GitHub license detection.

## Global Constraints

- Use the complete, unmodified Apache License, Version 2.0 with SPDX identifier `Apache-2.0`.
- Use `jacksoncai001` as the public copyright holder and 2026 as the copyright year.
- Do not relicense third-party dependencies, services, models, or externally authored material.
- Do not add user manuscripts, PDFs, extracted corpora, credentials, unpublished findings, or private review workspaces.
- Keep Issues, Projects, Discussions, and Wiki disabled; keep Pull Requests enabled.
- Keep the existing best-effort support policy and no-response-time commitment.
