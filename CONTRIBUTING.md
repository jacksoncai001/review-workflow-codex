# Contributing

Focused pull requests for concrete, reviewable improvements are welcome.

## License of contributions

Unless you explicitly state otherwise, any contribution intentionally submitted
for inclusion in this project is provided under the Apache License 2.0 (`Apache-2.0`), without
additional terms or conditions, consistent with section 5 of the license. Mark a
communication clearly as "Not a Contribution" if it is not intended for inclusion.

Only submit material that you have the right to license.

## Privacy boundary

Do not include manuscripts, PDFs, extracted private corpora, credentials,
unpublished findings, personal data, or generated private review workspaces.

## Checks

Run `uv lock --check`, `uv run ruff check .`, `uv run ruff format --check .`, and
`uv run pytest -q` before opening a pull request.
